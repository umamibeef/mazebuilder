# Maze Builder Playground

Interactive recursive-backtracker maze generator built with React, TypeScript, Vite, Tailwind, framer-motion, and lucide icons.

## Features

- Animated or instant maze generation
- Deterministic seed-based generation
- Adjustable straight/horizontal bias and braiding
- Live stats (visited cells, completion, stack depth, dead ends)
- Built-in shortest path solver visualization

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
